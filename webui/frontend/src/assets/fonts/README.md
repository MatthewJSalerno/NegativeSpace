# Inter

Inter Variable is bundled locally and served by Vite with the application; no
third-party font request is required. UI styles use weights 400 and 600.

Source: [official Inter repository](https://github.com/rsms/inter),
`docs/font-files/InterVariable.woff2`, retrieved 2026-09-28.
